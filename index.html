📊 Group Standings

6 groups of 4, round robin. Win = 2 pts, loss = 0. ①② are the auto-qualifiers. A ⚠ appears when a points tie needs a tie-breaker match.

🎯 Qualification

Top 2 of each group auto-advance (12). The six 3rd-place teams are ranked by points; the best 4 take the wildcard spots (16 total).

🏆 Knockout Bracket

Seeding: group winners are ranked by points and drawn against the weakest wildcards first; the rest seed by points. No two teams from the same group meet in the Round of 16.

⚙️ Live Sync & Tools

Currently running in Local-only mode — scores save on this device only. Add a Firebase config in the file to sync every phone live.

Turn on live sync (one-time, ~5 min)

  1. Go to console.firebase.google.com → Add project (skip Analytics).
  2. Build → Realtime Database → Create Database → start in Test mode.
  3. Project Settings ⚙ → Your apps → Web </> → copy the firebaseConfig.
  4. Open this file in a text editor, find FIREBASE_CONFIG near the top of the script, paste your values (especially databaseURL), save.
  5. Host it permanently (free): Firebase Hosting (firebase deploy), GitHub Pages, or claim a Netlify site with a free account. (A Netlify Drop without an account expires in ~1 hour.)
⚠️ Test-mode rules are open to anyone with the link for 30 days — fine for a one-day event.
